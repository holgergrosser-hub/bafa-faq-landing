## ✨ ANIMATIONS

### On Page Load:
1. **Navigation:** Slide down (200ms delay)
2. **Hero Title:** Fade + scale (400ms delay)
3. **Search Bar:** Scale in (600ms delay)
4. **CTA Buttons:** Fade up (800ms delay)

### On Scroll (Intersection Observer):
- **Trust Indicators:** Stagger fade-in (100ms delay each)
- **Category Cards:** Stagger fade-in (100ms delay each)
- **FAQ Items:** Subtle slide-in from left
- **CTA Boxes:** Scale from 0.95 to 1.0

### Micro-Interactions:
- **Buttons:** Scale(1.05) + shadow on hover
- **Cards:** Border color change + elevation
- **Links:** Underline animation (left to right)
- **Accordions:** Smooth height animation + chevron rotation

## 🎯 KEY DESIGN PRINCIPLES

1. **Clean Editorial** - Inspired by Linear, Stripe, Vercel
2. **Generous Whitespace** - 80-120px section padding
3. **Strong Hierarchy** - Clear H1 → H2 → H3 structure
4. **Consistent Spacing** - 4, 8, 16, 24, 32, 48px scale
5. **Subtle Depth** - Soft shadows, gradients, blur
6. **Smooth Motion** - 300ms ease-out transitions
7. **Professional B2B** - Serious, trustworthy, modern
8. **Conversion Focus** - 4 strategic CTA placements
